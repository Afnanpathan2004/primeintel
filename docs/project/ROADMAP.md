# Product Roadmap

## Phase 1: Internal Admin MVP (Current Scope)
- [x] Project architecture and persistent memory system.
- [ ] Next.js + Tailwind + Prisma SQLite foundation.
- [ ] Deterministic pricing engine with comprehensive test coverage.
- [ ] AI Requirement Analyzer (`gemini-3.8-flash` via `@google/genai` + resilient fallback).
- [ ] Fact vs Inference confidence scoring & missing information detector.
- [ ] Admin interactive review & calculation workflow.
- [ ] Market benchmark comparison layer.
- [ ] Discount engine with max cap and logged overrides.
- [ ] Estimate proposal generator with clean printable view.
- [ ] Audit logging and pricing rule manager.

## Phase 2: Post-MVP Internal Enhancements (V2)
- Multi-currency conversion (USD/INR/EUR/AED).
- Granular team roles (Estimator vs Commercial Approver).
- Automated proposal PDF generation via Puppeteer/React-PDF.
- Comparison mode (compare two requirement variations side-by-side).

## Phase 3: Future Website Integration (V3 - Explicitly Deferred)
- Public lead-gen estimator widget embedded on `primecoreinfo.com`.
- Anonymous customer estimate request flow with rate-limiting.
- Direct CRM synchronization (HubSpot / Salesforce).
- Customer self-service proposal portal.
